# ConsoleApp3

Консольный учебный проект на C# с реализациями простых обобщённых структур данных.

## Что внутри

- Стек с базовыми операциями добавления, извлечения и просмотра элемента.
- Список с добавлением, удалением, просмотром и преобразованием в массив.
- Вычисление среднего значения для числовых элементов стека.

## Запуск

Требуется .NET 8 SDK.

```bash
dotnet run --project ConsoleApp3/ConsoleApp3.csproj
```

Сборка решения:

```bash
dotnet build ConsoleApp3.sln
```
